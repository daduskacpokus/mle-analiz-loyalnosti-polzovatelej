# Анализ лояльности пользователей Яндекс Афиши

## Описание проекта

Проект переносит исследование удержания пользователей Яндекс Афиши из Jupyter Notebook в
Python-приложение с ООП. `DataProcessor` загружает заказы из PostgreSQL, очищает данные,
пересчитывает выручку из тенге в рубли, строит профили пользователей и рассчитывает
Retention, проверяет гипотезы и корреляцию `phi_k`.

## Структура

- `main.py` — точка входа: запускает обработку и выводит итоговый отчёт.
- `src/processing.py` — класс `DataProcessor` с методами загрузки, очистки и анализа.
- `config.py` — чтение параметров подключения к БД из `.env`.
- `data/final_tickets_tenge_df.csv` — курс тенге к рублю за 2024 год.
- `.env.example` — шаблон переменных окружения без реального пароля.

Файлы `.env`, `.venv` и содержимое `data/` исключены из Git.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python3 main.py
```

В `.env` нужно указать `DB_USER` и `DB_PWD`; остальные параметры подключения уже заполнены.

## Результаты анализа

- Исходная выгрузка: 290 611 заказов и 21 933 пользователя; после удаления 42 неявных
  дубликатов и очистки выручки осталось 287 363 заказа и 21 838 пользователей.
- 5 068 заказов в тенге пересчитаны в рубли. Удалены 381 заказ с отрицательной выручкой
  и 2 825 заказов выше 99-го перцентиля (2 628,42 руб.).
- После удаления 216 аномально активных пользователей итоговая выборка составила
  21 622 пользователя и 140 448 заказов.
- Средняя выручка с заказа — 522,97 руб., медиана — 347,30 руб. Средняя выручка по
  профилям — 545,34 руб.
- Доля пользователей с 2+ заказами — 61,3%. Сегмент с 5+ заказами — 28,3% аудитории,
  но 80,3% всех заказов.
- Средний интервал между заказами у вернувшихся — 16,2 дня, медиана — 8,5 дня.
- Выше среднего возвращаются пользователи выставок (64,2%), театра (63,4%) и концертов
  (61,8%); спорт даёт 55,8%.
- Desktop показывает возврат 63,8% против 60,8% у mobile. Топ-10 регионов дают 62,5%
  против 58,2% в остальных регионах.
- Гипотеза о более высоком возврате после спорта не подтвердилась: спорт ниже концертов
  на 6,0 п.п. Гипотеза о более высоком возврате в активных регионах подтвердилась:
  разница +4,4 п.п.
- Высокий средний чек не связан с возвратом: средние значения почти равны, но у
  вернувшихся выше медиана (496,54 против 378,87 руб.).
- Наибольшая связь с числом заказов у интервала между покупками (`phi_k` = 0,285),
  числа билетов (0,225) и средней выручки (0,219). Тип мероприятия, устройство и день
  недели связаны слабо (0,02–0,06).

## Рекомендации

1. Удерживать сегмент 5+ заказов: он формирует основную часть заказов.
2. Развивать лояльность в крупных регионах, театре и на выставках.
3. Для спорта проверить причины низкого возврата и запустить отдельные механики
   повторного вовлечения.
4. Стимулировать вторую покупку в первые две недели после первой.
5. Перенести успешный опыт desktop-сценария на мобильный интерфейс.
